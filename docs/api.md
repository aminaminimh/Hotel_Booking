# Overview

The web application exposes a REST API built with FastAPI.

The API receives booking information, preprocesses the data and returns the prediction generated by the trained XGBoost model.

# Architecture

```
                        Browser

                           ↓

                         FastAPI

                            ↓

                      Preprocessing

                            ↓

                         XGBoost

                            ↓

                        Prediction

                            ↓

                      JSON Response
```

# Endpoint

```
POST /predict
```

---

# Request Format

Content-Type

```
application/json
```

    "lead_time":30,
    "arrival_date_year":2016,

    "babies":0,

# Response

```json
{
    "prediction":0,
    "cancel_probability":0.12,
    "not_cancel_probability":0.88
}
```

# Prediction Meaning

Prediction

`0 --> Booking is expected to remain active.`


`1 --> Booking is likely to be cancelled.`

# Error Handling

The API automatically validates incoming requests using

`Pydantic`

Invalid requests return

`HTTP 422`

Internal server errors return

`HTTP 500`
