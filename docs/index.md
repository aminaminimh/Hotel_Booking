# Hotel Booking Cancellation Prediction

A Machine Learning project that predicts whether a hotel reservation is likely to be cancelled based on booking information available at the time of reservation.

## Project Overview

Hotel reservation cancellations can affect room allocation, revenue management, and demand forecasting.

This project uses an XGBoost classifier to estimate the likelihood of cancellation from reservation attributes such as:

- Lead time
- Hotel type
- Market segment
- Customer type
- Previous booking history
- Room type
- Deposit type
- Special requests
